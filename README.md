# الرياضيات للسابع — منصة تعليمية تفاعلية

موقع عربي RTL لمادة الرياضيات للصف السابع، المنهاج السوري. يُبنى بـ Next.js وReact وKaTeX ويُنشر موقعًا ثابتًا على [GitHub Pages](https://calesteer-create.github.io/Math_7th_Grade/)، من دون خادم أو قاعدة بيانات أو حسابات أو أسرار تشغيل. يحتوي التصميم على خط Cairo وملفات KaTeX محليًا. رابط WhatsApp اختياري للتواصل ولا يلزم للدروس.

## المحتوى الموجود

- فهرس الكتاب المصوّر: 8 وحدات و33 عنوان درس (أحد العناوين غير واضح في المصدر). صفحات الدروس التي لم تصل صورها تظل بانتظار المحتوى، ولا يُختلق لها شرح. السجل في `src/content/lesson-registry.json` هو مصدر الهوية والترتيب وحالة النشر، ولكل درس منشور معرّف ثابت وحزمة مستقلة.
- الدرس الأول **الأعداد الطبيعية** مكتمل من الصفحتين 3 و4: شرح مفصل بست أفكار، رسوم SVG، أمثلة وخطوات، مختبر، ست مهمات تفاعلية وحلولها المتدرجة، اختبار أصلي من 8 أسئلة، ودفتر من أربع أوراق قابلة للطباعة. ملفات `src/content/lesson-1.json` و`src/content/practice/` و`src/content/assessments/` هي مصدر المحتوى، ويعرض `/teacher/` حلول المصدر وإرشادات المعلم علنًا.
- لا توجد اختبارات وحدات جاهزة في المصدر؛ صفحاتها توضح أنها تنتظر اكتمال الوحدة وموافقة المالك. راجع [قواعد المحتوى](docs/CONTENT_STANDARDS.md).

## التشغيل والفحص

يلزم Node.js 22 وnpm. لا حاجة لملف `.env` أو إعداد قاعدة بيانات.

```bash
npm ci
npm run dev           # تطوير؛ المسار يبدأ بـ /Math_7th_Grade/
npm run typecheck
npm run lint
npm test              # اختبارات المحتوى والتصحيح
npm run build         # يتحقق من المحتوى ثم يخرج الموقع في out/
npm run check:export  # يفحص المسارات وروابط HTML وملفات CSS والخطوط
npm run preview       # معاينة out على http://localhost:3000/Math_7th_Grade/
```

لا يعمل `next start` مع التصدير الثابت؛ المعاينة أعلاه خادم ملفات محلي للاختبار فقط، وليس جزءًا من الموقع المنشور. لفحص المتصفح: `npx playwright install --with-deps chromium`، ثم شغّل `npm run test:browser`؛ يبدأ الاختبار معاينة الملفات تلقائيًا. تفحص اختبارات المتصفح نسخة `out` نفسها، بعرضي الحاسوب ومقاس هاتف، والروابط المباشرة والتحديث والتمارين والاختبار والطباعة. يمكن تحديد `PLAYWRIGHT_BASE_URL` عند الحاجة.

## النشر

ملف `.github/workflows/pages.yml` يبني ويفحص المشروع عند فتح أو تحديث طلب دمج إلى `main`، وينشر `out` تلقائيًا عند الدفع إلى `main` فقط بعد التحقق من أن الالتزام ناتج من طلب دمج مدمج، باستخدام GitHub Actions وGitHub Pages. لا تمتلك مهمة فحص طلب الدمج صلاحيات النشر. قبل أول نشر يجب اختيار **Settings → Pages → Build and deployment → Source: GitHub Actions** وتفعيل Pages/Actions بحسب إعدادات المستودع. لا حاجة لأسرار إضافية. لا يُنشَر فرع المراجعة تلقائيًا. المسار `/Math_7th_Grade` ثابت في `next.config.ts`؛ إذا تغير اسم المستودع يجب تحديثه وفحص المعاينة والروابط.

## الخصوصية والقيود

التصحيح والتلميحات والأنشطة تتم داخل JavaScript في المتصفح. تحفظ المحاولات وآخر محطة وملاحظات الدفتر في `localStorage` على الجهاز نفسه فقط؛ لا تتزامن بين الأجهزة أو المستخدمين، وقد تضيع عند مسح بيانات المتصفح. إذا مُنع التخزين فلن يمكن حفظ التقدم، لكن يمكن استخدام النشاط في الجلسة الحالية. لا توجد لوحة متابعة مركزية أو تسجيل دخول للمعلم أو الطالب.

لأن الموقع ثابت وعام، **ملفات الأسئلة ومفاتيحها وحلولها متاحة تقنيًا لأي زائر**، حتى إن واجهة الاختبار لا تعرض التفسير إلا بعد التسليم. لا يصلح ذلك لامتحان مراقب أو بيانات سرية. لا توجد خصوصية بين أشخاص يستخدمون المتصفح نفسه. الإصدار في مفتاح التخزين يفصل تقدم إصدارات الأنشطة؛ عند تغيير بنك الأنشطة غيّر `revision` عمدًا، فيبدأ الإصدار الجديد بسجل محلي مستقل.

## إضافة درس لاحقًا

أضف محتوى موثقًا من صور الكتاب، ومراحله ودفتره وحلوله واختباره وأنشطته معًا. الهوية والترتيب وحالة النشر في `src/content/lesson-registry.json`، ولكل درس ملفات حزمة (محتوى، بنك اختبار، بنك تمارين) مسجلة في فهارس `src/content/`. أبقِ المعرّفات الحالية مستقرة ولا تعِد ترقيمها عند الإضافة أو إعادة الترتيب. المدقق `scripts/validate-content.ts` يفحص تلقائيًا كل حزمة منشورة (المعرّفات، الربط بالوحدة، المراجع، أنواع الكتل، الحلول والتلميحات)، وصفحات `/lessons/<id>/` و`/quizzes/lesson/<id>/` تُبنى للمنشور فقط؛ ويشترط `check:export` غياب أي صفحة لدرس غير مكتمل. التفاصيل في [سجل الدروس](docs/LESSON_REGISTRY.md).
