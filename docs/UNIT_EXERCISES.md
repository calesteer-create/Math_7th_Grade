# تمرينات الوحدة

قسم مستقل عن حزم الدروس وحزم الاختبارات، مخصص لتغطية تمرينات الكتاب في نهاية الوحدة
كما وردت في الصور المصدرية. ملفاته لا تُخلط ببنوك الدروس، ولا تُحتسب في النقاط أو الإتقان.

## البنية

| المسار | الغرض |
| --- | --- |
| `src/content/unit-exercises/unit-<id>.json` | بيانات التمرينات والتصنيف والتلميحات والحلول |
| `src/content/unit-exercise-index.ts` | فهرس الوحدات التي لها قسم تمرينات |
| `src/lib/unit-exercises.ts` | الأنواع، والفحص الصارم، والتصحيح |
| `src/components/UnitExercises.tsx` | واجهة التمرين والتلميحات والتصحيح والحل |
| `src/components/unit-exercises/UnitExerciseFigure.tsx` | أشكال التمرينات (مستقيم أعداد وشبكة) |
| `src/app/units/[unitId]/exercises/page.tsx` | الصفحة المصدّرة لكل وحدة لها ملف تمرينات |

الشكل الأعلى للملف:

```json
{
  "unitId": 1,
  "revision": "unit-1-exercises-2026-11-22",
  "title": "تمرينات الوحدة الأولى",
  "intro": "…",
  "groups": [{ "id": "integer-operations", "title": "…", "description": "…", "lessonIds": [2, 3] }],
  "exercises": [{
    "key": "u1-08", "number": 8, "group": "integer-operations",
    "lessonId": 2, "lessonTitle": "الأعداد الصحيحة (الجمع والطرح)",
    "skill": "قيمة تعبير فيه طرح عدد سالب", "difficulty": "medium",
    "prompt": "…", "source": "تمرين 8 — ص 24", "figure": "line-marked",
    "fields": [{ "key": "a", "label": "…", "type": "signed-integer" }],
    "expected": { "a": "-9" },
    "hints": ["…", "…"], "commonMistakes": { "a": "…" },
    "solution": { "steps": [{ "title": "…", "text": "…" }], "final": "…" }
  }]
}
```

أنواع الحقول: `integer`، `signed-integer`، `choice` (مع `choices`)، و`range` (مع `min` و`max`
ويقبل أي عدد بينهما دون الحدين). لا يُستخدم أي حقل نصي حر، فالتصحيح دقيق ولا يعتمد على مطابقة صياغة.

## المدقق

`validateUnitExercises` يرفض أي حقل زائد أو ناقص، أو معرّف مكرر، أو مجموعة مجهولة،
أو درسًا غير معلن في مجموعته، أو خيارات ناقصة، أو قيمة تحقق خارج الخيارات، أو حلًا بأقل من
ثلاث خطوات، ويشترط تلميحين على الأقل وربط كل تمرين بصفحة مصدر. ويُشغَّل ضمن
`scripts/validate-content.ts` قبل `next build`، وكذلك في الاختبارات.

## التصحيح والحدود

- التصحيح يجري كله في المتصفح، ولا يُرسل شيء إلى خادم، ولا توجد مفاتيح مخفية.
- النتائج تُعرض في الجلسة الحالية فقط: لا تُكتب في `localStorage`، ولا تُضاف إلى نقاط الدرس،
  ولا تُحدّث خريطة المهارات، ولا تؤثر في حالة أي درس أو اختبار.
- الصفحة لا تُصدَّر إلا للوحدات الموجودة في `UNIT_EXERCISES_INDEX`، و`check:export`
  يتحقق من وجود صفحة كل ملف معتمد ومن غياب صفحات الوحدات الأخرى.
- ترتيب التمرينات داخل كل مجموعة تصاعدي: تمهيدي ثم تطبيقي ثم تحدٍّ، ويُذكر الدرس المرتبط
  بكل تمرين للرجوع إلى شرحه.

## وحدة 1

الملف `unit-1.json` يغطي تمرينات الصفحات 23–26 (التمرينات 1–21) في 25 بطاقة،
موزعة على خمس مجموعات: الأعداد على المستقيم، الصيغ العددية واللفظية، العمليات على
الأعداد الصحيحة، المقارنة والترتيب، وتطبيقات ومعلم المستوي. إحداثيات الأشكال المعاد رسمها
معلنة في `src/lib/coordinate-plane.ts`، ولا تُنسب إلى الكتاب قيمة مخمّنة.
